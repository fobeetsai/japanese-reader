# 日文閱讀助手 (Japanese Reading Assistant) 🇯🇵📖

> 仿 **句解霸 (en998.com/iread)** 閱讀拆解理念，專為日語自學者與閱讀者打造的智慧閱讀輔助系統。
> 深度聯動 **《絵でわかる日本語》941 條繁體中文文法資料庫** (https://fobeetsai.github.io/japanese-grammar/)。

🌐 **線上使用網址**：[https://fobeetsai.github.io/japanese-reader/](https://fobeetsai.github.io/japanese-reader/)

---

## ✨ 核心特色功能

1. **貼附文章與網址正文擷取**
   - 支援貼上任意日文文章、小說、新聞、讀解測驗題目。
   - 內建 3 組精選文摘（NHK 時事科技新聞、JLPT N2/N1 高階論說文、經典故事桃太郎）隨點隨讀。
   - 支援日文網址一鍵正文抓取（自動過濾廣告與導航雜訊）。

2. **JLPT N1~N5 單字分級色彩與浮動字典**
   - 內建 **8,138 筆 JLPT 單字等級與平假名讀音庫**。
   - 自動識別單字辭書形與詞性，依級數柔和著色：
     - **N1 高級**（紫色階）
     - **N2 中高**（藍色階）
     - **N3 中級**（綠色階）
     - **N4 初中**（橘色階）
     - **N5 基礎**（黃色階）
   - 點擊文章中任意單字，即時彈出浮動字典卡片，提供平假名讀音、發音朗讀 🔊、詞性、級數與繁中釋義。

3. **941 條文法自動標註與詳解抽屜**
   - 採用智慧長詞優先演算法，自動標註命中之 941 條文法句型（附藍色級數標籤，如 `[N2]`、`[N3]`）。
   - 點擊開啟頁內抽屜式詳解面板，展示接續規則、中文深度精解、精選例句與繁中翻譯。

4. **假名三模式切換（獨家遮蔽測驗）**
   - **顯示假名**：漢字上方顯示標準小字平假名（`<ruby><rt>`）。
   - **隱藏假名**：完全隱藏，鍛鍊漢字直讀力。
   - **遮蔽自測（獨家模式）**：假名讀音自動套用毛玻璃遮罩，**滑鼠懸停或點擊時才即時揭示讀音**，自主背單字測驗效果極佳！

5. **句解霸風格：整句深度分析器 (Sentence Deep Analyzer)**
   - 點擊文章中任意句子，右欄即時展開：
     - **本句原文（附假名）** 與高品質日語語音朗讀 🔊
     - **繁體中文精準翻譯**
     - **本句命中之 941 文法卡片**（接續規則 + 中文詳解 + 官方例句）
     - **本句單字拆解表格**：包含單字辭書形、讀音、文型／詞性、JLPT 級數、**繁體中文翻譯**與星號收藏！
     - 支援鍵盤快速鍵（`←` 上一句 / `→` 下一句）順暢翻頁。

6. **學習筆記本與匯出**
   - 支援收藏生詞與文法至本機筆記本，並能一鍵匯出為 `.txt` 檔案（方便匯入 Anki 複習）。

## 💻 離線與本機使用

本系統為 **100% 純前端單一靜態 HTML** 架構，無須安裝 Python 或啟動後端，直接滑鼠雙擊 `index.html` 即可在任何瀏覽器中流暢運行！
