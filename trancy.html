方式二：安裝 Chrome / Edge 擴充功能插件 (本專案已直接內建)

本專案目錄內已完整封裝好原生擴充插件 trancy_extension/：

  1. 在 Microsoft Edge 或 Google Chrome 網址列輸入 edge://extensions 或 chrome://extensions。
  2. 右上角開啟「開發人員模式 (Developer mode)」。
  3. 點擊左上角「載入未封裝項目 (Load unpacked)」。
  4. 選取本專案目錄下的 trancy_extension 資料夾，即可完成安裝！在任何日文網站自動開啟沉浸翻譯。
